## How to add a new network to Snapshot?

Snapshot supports EVM-compatible networks. To add a new network, you need to subscribe to the network plan. Once subscribed, Snapshot will take care of adding your network to the platform. For more details, visit [snapshot.box/#/network](https://snapshot.box/#/network).

For non-EVM networks, please contact the Snapshot team directly.

## What are the premium networks?

Snapshot supports many networks. However, some networks have full support ("premium") while others have limited support ("non-premium").

### Premium networks

* Ethereum
* Animechain
* ApeChain
* Arbitrum One
* Avalanche
* BNB Smart Chain
* Fraxtal
* Gnosis Chain
* Kava
* Linea
* Mantle
* Shibarium
* Sonic
* Starknet
* Story

If you want to upgrade a network from non-premium to premium, please follow the instructions at [snapshot.box/#/network](https://snapshot.box/#/network). Working closely with the Snapshot team will help you enable all premium features for your network.
