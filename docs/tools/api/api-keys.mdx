title: "API keys"
description: "To get higher rate limits on the Snapshot APIs, create an API Key."
---

API keys let your app make more requests to the Snapshot APIs: the Hub GraphQL API and the Score API. You can create and manage your keys yourself from the Snapshot app, then add a key to your requests to get its higher limits.

<Info>
You can use **the same API key** for different Snapshot APIs. Limits are **counted individually** per each API Service.
</Info>

## Limits

**🔓 No API Key:** 100 requests per minute.

**🔑 With the API Key:** 200,000 requests per month.

<Info>
If you are getting **close to 200k requests a month** contact our support on [Help center](/faq/support-and-feedback)
</Info>

## How can I get an API Key?

You can create your own keys from [Settings → API keys](https://snapshot.box/#/settings/api-keys) in the Snapshot app.

1. Connect your wallet. Your keys belong to the address of the wallet you connect, and Starknet wallets aren't supported yet.
2. Make sure your Snapshot profile has a name and an X (Twitter) handle. You can set them on your profile page, with the gear button (**Edit profile**).
3. Click **Authenticate** and sign the message with your wallet. This lets the page manage your keys without asking your wallet every time.
4. Click **New key**, enter a name for it and click **Create**. Your key is shown right away, with a button to copy it.

<Info>
A new key can take up to a minute before the APIs accept it.
</Info>

## How can I manage my keys?

All your keys are listed in [Settings → API keys](https://snapshot.box/#/settings/api-keys), with the number of requests each one made this month. Use the copy button next to a key to copy it again at any time.

Open the **⋯** menu of a key to:

- **Rename key**: give it a new name.
- **Delete key**: the key stops working within a minute. This can't be undone.

You can have up to 10 keys, each with a different name. The usage chart above the list shows your requests per day or month, for all your keys or for a single one.

## How to structure the query with my key?

The only change you need to make is to add the API Key in the headers of your request:

```bash
curl 'https://hub.snapshot.org/graphql?' \
  -H 'content-type: application/json' \
  -H 'x-api-key: <YOUR-API-KEY>' \
  --data-raw '{"query":"\n{\n space(id:\"snapshot.dcl.eth\"){\n  id\n  name\n  members\n}\n}","variables":null}' \
  --compressed
```

Alternatively, you can use the `apiKey` param in the query string with your key as a value:

```bash
curl 'https://hub.snapshot.org/graphql?apiKey=<YOUR_API_KEY>' \
  -H 'content-type: application/json' \
  --data-raw '{"query":"\n{\n space(id:\"snapshot.dcl.eth\"){\n  id\n  name\n  members\n}\n}","variables":null}' \
  --compressed
```

If you are using the [GraphQL interface](https://hub.snapshot.org/graphql), add your key in the **Request Headers** tab:

```json
{
  "x-api-key": "<YOUR-API-KEY>"
}
```
